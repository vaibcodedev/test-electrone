# Vault — расширение для Chrome

Увидели классный сайт, компонент или библиотеку — нажмите кнопку, и запись уже в Vault со скриншотом и ссылкой.

## Установка

1. Откройте `chrome://extensions` и включите **Режим разработчика** (переключатель справа сверху).
2. Нажмите **Загрузить распакованное** и выберите папку `extension`:
   - в установленной версии Vault: **Настройки → Расширение для Chrome → Открыть папку расширения**;
   - при разработке: папка `extension` в корне репозитория.
3. Закрепите иконку Vault на панели Chrome (значок пазла → булавка).

Горячая клавиша: **Ctrl+Shift+S** (на Mac — **Cmd+Shift+S**). Изменить можно в `chrome://extensions/shortcuts`.

## Подключение

1. Запустите Vault (достаточно, чтобы он висел в трее).
2. В Vault откройте **Настройки → Расширение для Chrome** и скопируйте **ключ** и **порт** (по умолчанию 47219).
3. В расширении: правый клик по иконке → **Параметры** (или кнопка «Настройки» в окне), вставьте ключ, нажмите **Проверить подключение**.

Если ключ поменяли в Vault («Сгенерировать новый»), обновите его и здесь.

## Куда сохраняется

| Цель | Что создаётся в Vault |
| --- | --- |
| **Дизайн** | Карточка в «Дизайнах» со скриншотом и ссылкой на оригинал. Нужен скриншот. |
| **Закладка** | Закладка «прочитать». Тип (видео, курс, репозиторий, статья) определяется по сайту. Выделенный текст попадает в заметки. |
| **Библиотека** | Для npm и GitHub подставляются название, ссылки и команда установки, описание берётся из npm. Статус «Хочу попробовать». |
| **Компонент** | Компонент со скриншотом-обложкой. Выделенный на странице код становится кодом компонента. |
| **Вакансия** | Вакансия в статусе «Сохранено». Площадка определяется по адресу (Djinni, DOU, LinkedIn…), выделенный текст — описание. |

Цель подсказывается автоматически по адресу страницы, а последний выбор запоминается для каждого сайта.

## Скриншот

- **Видимая область** — то, что сейчас на экране.
- **Выделить область** — окно закроется, выделите прямоугольник мышью (Esc — отмена). Окно откроется снова со скриншотом (в старых версиях Chrome на иконке появится «1» — нажмите на неё ещё раз).
- **Без скриншота**.

На служебных страницах Chrome (`chrome://…`, магазин расширений) выделение области и чтение выделенного текста недоступны.

## Приватность

Расширение обращается только к `http://127.0.0.1` — к Vault на этом компьютере. Каждый запрос подписан ключом, без него Vault ничего не принимает. Никаких внешних серверов, аналитики и удалённого кода.
