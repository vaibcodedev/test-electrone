# Vault — розширення для Chrome

Побачили класний сайт, компонент або бібліотеку — натисніть кнопку, і запис уже у Vault зі скриншотом і посиланням.

## Встановлення

1. Відкрийте `chrome://extensions` і ввімкніть **Режим розробника** (перемикач праворуч угорі).
2. Натисніть **Завантажити розпаковане** й оберіть папку `extension`:
   - у встановленій версії Vault: **Налаштування → Розширення для Chrome → Відкрити папку розширення**;
   - під час розробки: папка `extension` у корені репозиторію.
3. Закріпіть іконку Vault на панелі Chrome (значок пазла → шпилька).

Гаряча клавіша: **Ctrl+Shift+S** (на Mac — **Cmd+Shift+S**). Змінити її можна в `chrome://extensions/shortcuts`.

## Під’єднання

1. Запустіть Vault (достатньо, щоб він був у треї).
2. У Vault відкрийте **Налаштування → Розширення для Chrome** і скопіюйте **ключ** і **порт** (за замовчуванням 47219).
3. У розширенні: правий клік по іконці → **Параметри** (або кнопка «Налаштування» у вікні), вставте ключ, натисніть **Зберегти й перевірити**.

Якщо ключ змінили у Vault («Згенерувати новий»), оновіть його й тут.

## Куди зберігається

| Ціль | Що створюється у Vault |
| --- | --- |
| **Дизайн** | Картка в «Дизайнах» зі скриншотом і посиланням на оригінал. Потрібен скриншот. |
| **Закладка** | Закладка «прочитати». Тип (відео, курс, репозиторій, стаття) визначається за сайтом. Виділений текст потрапляє в нотатки. |
| **Бібліотека** | Для npm і GitHub підставляються назва, посилання й команда встановлення, опис береться з npm (для GitHub — лише якщо пакет посилається на цей репозиторій). Інша сторінка зберігається як документація. Статус «Хочу спробувати». |
| **Компонент** | Компонент зі скриншотом-обкладинкою. Виділений на сторінці код стає кодом компонента. |
| **Вакансія** | Вакансія в статусі «Збережено». Майданчик визначається за адресою (Djinni, DOU, LinkedIn…), виділений текст — опис. |

Ціль підказується автоматично за адресою сторінки, а останній вибір запам’ятовується для кожного сайту. Введене у формі не губиться, якщо вікно закрилося (клік повз нього): відкрийте розширення на тій самій вкладці ще раз.

Зберегти: кнопка **Зберегти у Vault**, **Enter** в однорядковому полі або **Ctrl+Enter**. Після збереження — **Відкрити у Vault** (запис відкриється в застосунку) або **Зберегти ще**.

## Скриншот

- **Видима область** — те, що зараз на екрані.
- **Виділити область** — вікно закриється, виділіть прямокутник мишею (Esc — скасувати). Вікно відкриється знову зі скриншотом (у старих версіях Chrome на іконці з’явиться «1» — натисніть на неї ще раз).
- **Без скриншота**.

На службових сторінках Chrome (`chrome://…`, магазин розширень) виділення області й читання виділеного тексту недоступні.

## Приватність

Розширення звертається лише до `http://127.0.0.1` — до Vault на цьому комп’ютері. Кожен запит підписано ключем, без нього Vault нічого не приймає. Жодних зовнішніх серверів, аналітики чи віддаленого коду.
