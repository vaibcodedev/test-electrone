# План доработок Vault

Отобрано из предложений 25.11.2026. Статусы: «запланировано» → «в работе» → «готово» (с номером беты); «предложение» — нужно ваше «так» или правка.

**Очередь:** сейчас идут шесть функций (разделы меню, свёрнутое меню, «Сховище», тестовый режим, добірки, обране) и пункт 2. Дальше — раунд исправлений (регрессии, скелетоны, доступность WCAG), затем пункты, отмеченные «делаем» (11, 12, 9), потом остальные по номерам.

## 1. Автобекап в выбранную папку

**Статус:** запланировано · **объём:** небольшой

Сейчас бекапы лежат рядом с базой: если умрёт диск — умрут и они.

- В «Налаштування → Бекап» — выбор папки для копий (например, папка OneDrive или Google Drive, которую синхронизирует их клиент).
- Ротация: хранить последние N копий (по умолчанию 10), старые удалять.
- После каждой копии — проверка, что она читается (открыть копию базы только на чтение и сверить число записей).
- Если папка недоступна (отключён диск, облако не запущено) — понятное уведомление, основная работа не страдает.

## 2. Расширение Chrome: «Сніпет», «Нотатка», «Помилка»

**Статус:** в работе · **объём:** небольшой

Сейчас расширение сохраняет дизайн, закладку, бібліотеку, компонент и вакансію. Для разработчика самое частое — код.

- Новые цели в попапе: «Сніпет» (выделенный код, язык определяется сам), «Нотатка» (выделенный текст + ссылка на страницу), «Помилка» (текст ошибки + ссылка, где нашли решение).
- Подсказка цели по сайту: GitHub/StackOverflow → «Сніпет».

## 3. Повторяющиеся завдання и экспорт календаря в .ics

**Статус:** запланировано · **объём:** средний · *«можно сделать в принципе»*

- Картка повторяется: каждый день / неделю (выбранные дни) / месяц; после «Готово» создаётся следующая.
- Экспорт календаря в файл .ics (и, по желанию, постоянная ссылка-подписка), чтобы видеть события в календаре телефона.

## 4. Поиск Ctrl+K: фильтр по типу и поиск в PDF

**Статус:** запланировано · **объём:** средний · *«можно»*

- Префиксы прямо в палитре: `сн:` — сніпети, `нт:` — нотатки, `ід:` — ідеї и т. д.; подсказка префиксов при вводе.
- Поиск по тексту вложенных PDF (текст извлекается при добавлении файла и попадает в поисковый индекс).

## 5. Канбан: шаблоны карток, лимит «в роботі», прокрутка при перетаскивании

**Статус:** запланировано · **объём:** средний

- Шаблоны карток (название, чек-лист, мітки) — «Нова картка з шаблону».
- Лимит карток на колонку (WIP): колонка подсвечивается, когда лимит превышен.
- При перетаскивании картки к краю доски она прокручивается сама.

## 6. «Підсумки тижня»: динамика за 4–8 недель

**Статус:** запланировано · **объём:** средний

- Мини-графики у метрик (завдання, ідеї, нотатки, час) за последние 4–8 недель, а не только сравнение с прошлой неделей.

## 7. Ошибки загрузки — на месте, а не вечным тостом

**Статус:** частично готово · **объём:** небольшой

- ✅ Тост ошибки загрузки больше не висит, пока его не закроют: 12 секунд (пауза при наведении), без крестика в углу, текст по-украински (коммит 2ff8fd6).
- ☐ Показывать ошибку прямо в том месте, где не загрузилось (карточка, список, панель записи) с кнопкой «Повторити», а тост оставить только как запасной вариант.

## 8. Проект как центр («Розробка»)

**Статус:** запланировано · **объём:** средний

Сейчас проект в «Розробці» — папка со скриптами и статусом git, а его дошка, нотатки, сніпети и помилки живут по своим разделам.

- Страница проекта собирает всё связанное: дошка, нотатки, сніпети, помилки, закладки. Связь — через обычные «Зв’язки» и мітку проекта; при открытии Vault подсказывает записи, где упоминается имя проекта («Зв’язати всі»).
- Кнопки «Відкрити в редакторі» (редактор из настройки «Типовий редактор») и «Термінал тут» (Windows Terminal, если есть, иначе PowerShell в папке проекта).
- «Перевірити залежності»: сводка «N пакетів застаріли · M відомих вразливостей (K критичних)» и таблица «пакет → зараз → остання → тип оновлення». Запускаются только две фиксированные команды на чтение (`npm outdated --json`, `npm audit --json`) — это осознанное исключение из правила «в проектах запускаются только скрипти з package.json»; ничего не устанавливается и не меняется.
- Результат проверки хранится с датой («перевірено 3 дні тому»), чтобы не гонять npm при каждом открытии.

## 9. План в «Підсумках» → картки

**Статус:** запланировано · **объём:** небольшой · *«пофиг, добавляй»*

- Под полем «План на наступний тиждень» кнопка «Створити картки» (видна, когда в плане есть строки `- [ ]`).
- Диалог: какую дошку и колонку взять, список строк с галочками (все отмечены), «Створити N карток».
- Созданные строки в плане помечаются ссылкой на картку, повторное нажатие не создаёт дублей.

## 10. Офлайн-копия закладки (режим чтения)

**Статус:** запланировано · **объём:** средний

- При сохранении закладки Vault кладёт к себе чистый текст статьи (без меню, рекламы и комментариев) — как «режим чтения» в браузере.
- Лучший источник — расширение: у него уже открыта страница, оно отдаёт статью сразу (библиотека Readability от Mozilla, Apache-2.0). Для закладок, добавленных в самом Vault, — загрузка страницы в изолированном окне и та же обработка.
- В записи закладки — вкладка «Читати» с нормальной типографикой; текст попадает в поиск Ctrl+K; первая версия — только текст и заголовки, без картинок.

## 11. Англійська: щоденна ціль, вимова, імпорт, граматика

**Статус:** запланировано, делаем · **объём:** средний · *«делай только красиво и по лучшим практикам … минимум усилий, максимум пользы»*

Минимум кода — максимум пользы для учёбы (как в Anki и Duolingo, без лишнего):

- **Щоденна ціль.** В настройках раздела: «Нових слів на день» (по умолчанию 10) и «Повторень на день, не більше» (по умолчанию 100). Сессия берёт сначала повторения, потом новые — сколько осталось до цели.
- **Прогрес дня на странице.** Кольцо «Сьогодні: 7 з 10 нових · 18 повторень», серия днів поспіль («🔥 12 днів» — без эмодзи, нашей иконкой), кнопка «Тренуватися» — один главный вход.
- **Вимова 🔊.** Встроенный синтез речи Windows (Web Speech API): кнопка у слова и на карточке тренажёра, выбор голоса (американский / британский) в настройках раздела, по желанию — автопроизношение при показе слова. Бесплатно, офлайн, без ключей.
- **Імпорт.** Файл CSV/TSV или экспорт Anki «як текст»: предпросмотр, выбор колонок «слово / переклад / приклад», пропуск дублей, «Імпортувати N слів».
- **Статистика.** Вивчено за тиждень/місяць (мини-график), всего «вивчено / вчу / нові», точность ответов.
- **Граматика (просто).** Новый вид записи «Правило» (Past Simple и т. п.): коротко правило + примеры. В тренажёре — карточки «заповни пропуск» из примеров по тому же интервальному повторению, что и слова. Отдельный фильтр «Граматика» в словаре.

## 12. Ссылки `[[…]]` и обратные ссылки

**Статус:** запланировано, делаем · **объём:** средний

- В любом поле Markdown набираете `[[` — всплывает список записей с поиском (как в Obsidian/Notion); выбор вставляет ссылку. В тексте хранится id записи, поэтому переименование ссылку не ломает.
- В просмотре ссылка кликабельна и открывает запись; у удалённой записи — зачёркнута с подсказкой «у кошику».
- В записи, на которую сослались, — блок «Згадки»: откуда сослались и фрагмент текста вокруг ссылки. Отличается от ручных «Зв’язків» (те остаются как есть).

## 13. ШІ по своему ключу: чат, действия, скіли, агенты

**Статус:** предложение · **объём:** большой — делаем по частям · *«давай продумаем»*

Цены и бесплатные варианты провайдеров — добавлю таблицу, когда закончит исследование.

- **Подключение.** «Налаштування → Штучний інтелект» (по умолчанию выключено): провайдер — Anthropic Claude, OpenAI-совместимый адрес (покрывает OpenRouter, Groq, DeepSeek, Mistral и бесплатные локальные Ollama / LM Studio), Google Gemini; ключ — в защищённом хранилище Windows (safeStorage); выбор модели; «Перевірити підключення». Запросы идут только из main, ключ в интерфейс не попадает.
- **Чат.** Панель справа (горячая клавиша), видит открытую запись как контекст. Внизу — быстрые действия-кнопки: «Додати як ідею / картку / нотатку», «Придумати варіанти», «Підсумувати», «Перекласти», «Зробити картки для англійської».
- **Действия — только с подтверждением.** ИИ не пишет в базу сам: он предлагает действие («створити картку X на дошці Y»), вы видите превью и жмёте «Застосувати». Разрешённые действия — создать и найти записи; удалять — никогда.
- **Скіли.** Шаблон-инструкция для ИИ, хранится в разделе «Claude» (у него уже есть вид «Скіл»): «Писати як людина — без ознак ШІ», «Коротко й по ділу», «Українською», «Відгук на вакансію у моєму стилі»… Выбирается в чате одним кликом, свои добавляются как обычные записи.
- **Агенты.** Агент = скіл + набор разрешённых действий + модель. Примеры: «Помічник з відгуків» (читает вакансию, пишет відгук вашим стилем), «Англійська» (делает картки и примеры), «Організатор» (предлагает мітки и теки для новых нотаток). Работают по шагам, каждое изменение — с подтверждением.
- **«Спитати свою базу».** Сначала обычный поиск по вашим записям, лучшие находки — в контекст, ответ со ссылками на записи. Позже — смысловой поиск (эмбеддинги локально).
- **Стоимость и приватность.** Счётчик токенов и примерной стоимости за месяц, лимит; перед первым запросом — что именно уходит провайдеру (у локальных моделей — ничего).

## 14. Таймеры по всему проекту

**Статус:** предложение — нужно ваше «так» · **объём:** средний · *«я не знаю как таймеры правильно организовать по проекту»*

Как это устроено в Toggl/Clockify и подходит Vault:

- **Один активный таймер на всё приложение.** Запуск ▶ с любой картки, проекта CRM, проекта «Розробки» или прогона чек-листа; запуск нового останавливает предыдущий.
- **Виден всюду.** «Пилюля» в шапке окна: название и время; клик — открыть запись, ■ — остановить. В трее — то же.
- **Простой.** Если компьютер не трогали дольше 10 минут — при возвращении вопрос «Залишити / Відкинути 23 хв».
- **Записи часу** — одна общая таблица с привязкой к любой записи; нынешние записи контрактов CRM переносятся без потерь (миграция только добавляет, ничего не удаляет). Записи можно поправить вручную.
- **Отчёты.** На картке и в проекте — сумма времени; в «Підсумках тижня» — время по дошкам и проектам; в контрактах — как сейчас (оплачиваемые часы).
- **По желанию — Pomodoro** (25/5) с уведомлениями.
