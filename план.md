## 8. Проект как центр («Розробка»)

**Статус:** запланировано · **объём:** средний

Сейчас проект в «Розробці» — папка со скриптами и статусом git, а его дошка, нотатки, сніпети и помилки живут по своим разделам.

- Страница проекта собирает всё связанное: дошка, нотатки, сніпети, помилки, закладки. Связь — через обычные «Зв’язки» и мітку проекта; при открытии Vault подсказывает записи, где упоминается имя проекта («Зв’язати всі»).
- Кнопки «Відкрити в редакторі» (редактор из настройки «Типовий редактор») и «Термінал тут» (Windows Terminal, если есть, иначе PowerShell в папке проекта).
- «Перевірити залежності»: сводка «N пакетів застаріли · M відомих вразливостей (K критичних)» и таблица «пакет → зараз → остання → тип оновлення». Запускаются только две фиксированные команды на чтение (`npm outdated --json`, `npm audit --json`) — это осознанное исключение из правила «в проектах запускаются только скрипти з package.json»; ничего не устанавливается и не меняется.
- Результат проверки хранится с датой («перевірено 3 дні тому»), чтобы не гонять npm при каждом открытии.

## 9. План в «Підсумках» → картки

**Статус:** запланировано · **объём:** небольшой · *«пофиг, добавляй»*

- Под полем «План на наступний тиждень» кнопка «Створити картки» (видна, когда в плане есть строки `- [ ]`).

## 10. Офлайн-копия закладки (режим чтения)

**Статус:** запланировано · **объём:** средний

- При сохранении закладки Vault кладёт к себе чистый текст статьи (без меню, рекламы и комментариев) — как «режим чтения» в браузере.
- Лучший источник — расширение: у него уже открыта страница, оно отдаёт статью сразу (библиотека Readability от Mozilla, Apache-2.0). Для закладок, добавленных в самом Vault, — загрузка страницы в изолированном окне и та же обработка.
- В записи закладки — вкладка «Читати» с нормальной типографикой; текст попадает в поиск Ctrl+K; первая версия — только текст и заголовки, без картинок.

## 11. Англійська: щоденна ціль, вимова, імпорт, граматика

**Статус:** запланировано, делаем · **объём:** средний · *«делай только красиво и по лучшим практикам … минимум усилий, максимум пользы»*

Минимум кода — максимум пользы для учёбы (как в Anki и Duolingo, без лишнего):

- **Щоденна ціль.** В настройках раздела: «Нових слів на день» (по умолчанию 10) и «Повторень на день, не більше» (по умолчанию 100). Сессия берёт сначала повторения, потом новые — сколько осталось до цели.
- **Прогрес дня на странице.** Кольцо «Сьогодні: 7 з 10 нових · 18 повторень», серия днів поспіль («🔥 12 днів» — без эмодзи, нашей иконкой), кнопка «Тренуватися» — один главный вход.
- **Вимова 🔊.** Встроенный синтез речи Windows (Web Speech API): кнопка у слова и на карточке тренажёра, выбор голоса (американский / британский) в настройках раздела, по желанию — автопроизношение при показе слова. Бесплатно, офлайн, без ключей.
- **Імпорт.** Файл CSV/TSV или экспорт Anki «як текст»: предпросмотр, выбор колонок «слово / переклад / приклад», пропуск дублей, «Імпортувати N слів».
- **Статистика.** Вивчено за тиждень/місяць (мини-график), всего «вивчено / вчу / нові», точность ответов.
- **Граматика (просто).** Новый вид записи «Правило» (Past Simple и т. п.): коротко правило + примеры. В тренажёре — карточки «заповни пропуск» из примеров по тому же интервальному повторению, что и слова. Отдельный фильтр «Граматика» в словаре.

## 13. ШІ по своему ключу: кнопки ✦, скіли, агенты

**Статус:** запланировано (остаток); порядок — точечные кнопки → скіли → агенты. Вся карта одобрена 25.11.2026: скіли и защита — «давай», агенты — «можно попробовать» · **объём:** большой

**Точечные кнопки** (ИИ ничего не меняет сам: превью → «Застосувати» / «Скасувати»):

- Любая запись → шапка → «✦» → Покращити текст / Скоротити / Перекласти / Згенерувати опис → превью изменений → Застосувати;
- Дошки → картка → «✦ Розбити на підзадачі»;
- Чек-листи → шаблон → «✦ Згенерувати пункти»;
- Імпорт з JSON (во всех разделах) → «✦ Згенерувати» → задача словами → JSON сразу в превью импорта → Імпортувати;
- Фриланс → Відгуки → «✦ Чернетка відгуку» (из текста вакансии и шаблона);
- Пошук роботи → Вакансії → «✦ Розібрати вакансію» (посада, компанія, вимоги, стек);
- Питання до співбесіди → «✦ Перевірити відповідь»;
- Помилки й рішення → «✦ Пояснити помилку»;
- Англійська → слово → «✦ Приклади й переклад»;
- Підсумки тижня → «✦ Короткий підсумок».

**Скіли.** Налаштування → ШІ → Скіли: шаблоны инструкций («Писати як людина — без ознак ШІ», «Коротко й по ділу», «Українською», «Відгук на вакансію у моєму стилі», свои). Хранятся в разделе «Claude» (там уже есть вид «Скіл»), свои добавляются как обычные записи; в чате — через «/», в действиях подставляются сами.

**Агенты.** Налаштування → ШІ → Агенти: агент = цепочка скілов + набор разрешённых действий + модель («Помічник з відгуків», «Англійська», «Організатор», «Тижневий огляд»); запуск из чата («/агент») или кнопкой; каждое изменение — карточкой «Застосувати»; явно указано, что агенту можно читать и создавать; удалять — никогда.

**Позже:** смысловой поиск для «Спитати свою базу» (эмбеддинги локально, например bge-m3 — понимает украинский); примерная стоимость запросов за месяц (перед работой проверить, чего не хватает в счётчике).

*Предложение:* короткая справка по разделам в чате — из гайда (`guide/sections.tsx`) по запросу «як…», а не только из `APP_HELP`.

## 14. Таймеры по всему проекту

**Статус:** предложение — нужно ваше «так» · **объём:** средний · *«я не знаю как таймеры правильно организовать по проекту»*

Как это устроено в Toggl/Clockify и подходит Vault:

- **Один активный таймер на всё приложение.** Запуск ▶ с любой картки, проекта CRM, проекта «Розробки» или прогона чек-листа; запуск нового останавливает предыдущий.
- **Виден всюду.** «Пилюля» в шапке окна: название и время; клик — открыть запись, ■ — остановить. В трее — то же.
- **Простой.** Если компьютер не трогали дольше 10 минут — при возвращении вопрос «Залишити / Відкинути 23 хв».
- **Записи часу** — одна общая таблица с привязкой к любой записи; нынешние записи контрактов CRM переносятся без потерь (миграция только добавляет, ничего не удаляет). Записи можно поправить вручную.
- **Отчёты.** На картке и в проекте — сумма времени; в «Підсумках тижня» — время по дошкам и проектам; в контрактах — как сейчас (оплачиваемые часы).
- **По желанию — Pomodoro** (25/5) с уведомлениями.

## 15. Иконки и 3D-картинки в интерфейсе

**Статус:** запланировано, делаем после текущих функций · **объём:** средний · *«мне нравиться єти и єти»* — выбраны №14 и №2 из листа сравнения

- **Иконки — Duoicons** (MIT, мягкий duotone; вариант «акцент: подложка лаймом»): плитки главной и «Знань», небольшие иконки пустых состояний, быстрые действия. Встраиваются как SVG, цвета берутся из наших токенов, поэтому сами подстраиваются под тёмную и светлую тему. Где у набора нет нужного смысла — ближайшая по теме иконка того же набора, без смешивания стилей.
- **3D-картинки — 3dicons Premium** (CC0, графит + золото): крупная картинка на пустых экранах модулей, «Вільний день» / «Усе зроблено» на главной, «Тихий тиждень», «Такої сторінки немає», пустой кошик, гайд. Не больше одной на экран; где на экране уже есть лаймовая кнопка, картинка меньше и спокойнее, чтобы золото не спорило с акцентом.
- Файлы — локально в приложении (без интернета), уменьшены до нужного размера; тексты лицензий (MIT Duoicons, CC0 3dicons) — в файле лицензий установщика.
- Карта мест — по разметке, уже собранной агентом (какой объект на каком экране); правило «где картинка уместна, а где нет» — в docs/design-system.md.

## 19. Контекстні меню: система

**Статус:** одобрено пользователем, в работе · макети й карта меню: https://claude.ai/artifact/B5xqmhCKfdFZzwPZ7w3UZ5

Выбрано: вигляд А (спокійний список) · обсяг 2 · меню тексту своє (shadcn), сначала проверить, не теряется ли выделение; если ненадёжно — системное Electron · кнопка «⋯» на плитках при наведении и фокусе.

Осталось:
- **Меню тексту, посилань і коду:** событие `context-menu` в main → своё меню в renderer; орфография, «Додати в словник», вирізати / копіювати / вставити / без форматування / виділити все (недоступное — неактивно); посилання: відкрити, копіювати адресу; код: копіювати блок.
- **Спільне меню записів:** действия описываются один раз на тип записи; из них — правый клик и «⋯». Сначала проба на двух разделах, потом остальные по карте из макетов (включая доступи, фінанси, вкладення, локальні проєкти, кошик, головну).
- **Порядок груп:** відкрити й головна дія → зміна стану → закріпити й копіювати посилання → «У кошик» зі «Скасувати». До трёх-четырёх групп, подменю одного уровня; недоступное в меню записей прятать; клавиши — только существующие.
- Нет в коде и входит в объём: копіювати посилання на запис, копіювати зображення, копіювати шлях проєкту, зняти мітку зі списку мітки. Для проектов и вложений не все общие действия поддерживает модель.
- Не входит (обсяг 3, отдельно по просьбе): вибір кількох записів, меню порожнього місця, дублювання.
